# Reuse disclosure

Countersign was written during the submission period of the AWS Agents for
Humans hackathon. Everything in `src/`, `tests/`, `scripts/`, `tools/` and
`docs/` is original to this project.

Two things are worth naming explicitly.

**Shared tooling shape.** I entered this hackathon twice, and my Good Neighbour
track entry uses the same broad harness shape: a Playwright script that drives
the deployed UI and fails on console errors, and a demo pipeline that records
the product while an Edge TTS narration plays. The Countersign versions in
`tools/ui_smoke.py` and `demo_video/` are written for this product's screens and
this product's assertions. No source file is shared between the two projects.

**Standard dependencies.** Strands Agents, boto3, Starlette, uvicorn, Pydantic
and Playwright are used as published. `requirements.lock` pins every transitive
dependency by hash.

**The demonstration data is invented.** Kestrel Pay, Northwind Systems and
Brandt Werke do not exist. Every person, system, repository, ticket, vendor and
figure in `src/countersign/corpus/` is generated by `scripts/build_corpus.py`
and derives from no real organisation's records. What is drawn from experience
is the *shape* of the conditions planted in them, which is the part a control
has to survive.
